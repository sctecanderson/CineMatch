# Navegação

As páginas HTML de entrada usam os mesmos módulos e estilos. A navegação interna usa hash (#/home, #/movies, #/tv-shows, #/recomendacoes, #/detail/ID, #/watchlist, #/admin/dashboard).

O painel mantém as seções administrativas do pacote de referência, com registros persistidos apenas no navegador. Os dados de referência não representam acesso aos serviços privados da IQONIC. As séries TVMaze são carregadas separadamente e entram no catálogo público e no recomendador.

Para executar e conhecer limitações, consulte ../LEIA-ME.md.
